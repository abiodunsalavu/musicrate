# About musicrate
musicrate is a social cataloguing web-app that allows users to rate, review and and organise their favourite albums into a beautiful collection for everyone to see!
## Features 
- Search for albums, mixtapes and EPs!
- Rate your music out of 5 stars
- Write reviews discussing your opinion on music
- Each user having their own profile with their own collections
- Follow other users and comment on their reviews
## Tech Stack 
- Next.js
- Tailwind CSS
- JavaScript
- React
- Supabase
- Spotify Web API
## API
This project uses the Spotify Web API to retrieve:
- Artist information
- Albums
- Tracks
- Genres
- Album artwork
